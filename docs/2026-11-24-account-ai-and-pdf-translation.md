# MyEasyPaper 更新说明：账户 AI 设置与 PDF 翻译

记录日期：2026-11-24。

**这是源码更新记录，不是发布公告。** 本次更新纳入仓库源码；生产环境未部署此版本。[账户 AI 部署草案](2026-11-24-account-ai-deployment-draft.md)不是现网操作指南。部署须单独发布配套镜像并完成预生产验收。

## 账户 AI 供应商与模型

- 在「设置 → AI」中，每个账户独立管理多个供应商、模型和自己的默认模型。API Key 不在账户间共享，也不会在页面回显。网页账户请求没有可用的账户配置时，不会回退到服务器全局凭据；用户仍可登录和阅读已有论文。
- 支持 OpenAI 兼容的 Chat Completions 与 Responses，按供应商配置选择协议。输出预算取业务请求上限和模型设置上限中的较小值，分别以 `max_tokens` 和 `max_output_tokens` 随请求发送。请求前以可用的输入 token 估算加上输出预算检查上下文窗口。图片输入和思考强度按模型声明的能力处理，不把不支持的能力当作可用。
- 「发现模型」失败时仍可手动添加或维护模型。连接测试用选定模型发送一条最小真实请求，执行前会提示供应商可能计费。模型目录能读取不等于模型推理可用。
- 思考档位使用固定选项的下拉多选：`none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。界面直接显示 `medium`；新建模型的可选档位初始勾选 `low`、`high`、`max`，不是同时发送三个值。不提供自定义档位；保留思考能力开关、API 参数配置和默认档位设置，后端契约不变。模型支持时，实际请求按所选协议和模型配置传递对应的档位值。

## 后续部署前的条件

- 待配套源码与部署配置发布后，服务器须持久保存账户 API Key 的加密密钥环和活动版本，分别由 `EASYPAPER_CREDENTIAL_ENCRYPTION_KEYS`、`EASYPAPER_CREDENTIAL_ENCRYPTION_ACTIVE_VERSION` 配置。生产后端缺少有效密钥配置时不会启动。已有单密钥部署须保留 `EASYPAPER_CREDENTIAL_ENCRYPTION_KEY` 对应的原密钥，迁移时纳入密钥环，不能重新生成覆盖。
- 轮换时先让后端同时加载新旧版本，再切换活动版本、备份并重封装旧凭据；确认无待迁记录或错误后再退役旧版本，保留解密历史备份所需的密钥。服务器还须能连通实际供应商端点。
- 现网仍以[现行部署指南](DEPLOYMENT.md)为准。新装初始化、旧 Worker 迁移和加密密钥轮换见[未发布部署草案](2026-11-24-account-ai-deployment-draft.md)，仅在配套版本发布且完成预生产验证后适用。

## PDF 翻译修复

- 网页 PDF 翻译通过当前账户的 AI 供应商 API 调用，不依赖 Codex 服务或 CLI。已分类的 `AIError` 保留安全错误码和处理建议；未分类的异常才使用 `AI_PDF_TRANSLATION_FAILED`，提示检查模型配置或稍后重试。
- 译后 PDF 生成后，对齐文件（`.alignment.json`）现在显式用 UTF-8 写入。此前若系统默认编码不能写入译文字符，会触发 `UnicodeEncodeError`：磁盘上可能已有译后 PDF，但数据库事务回滚，任务没有保存结果路径。修复覆盖结果保存阶段，不代表供应商错误已经修复。
